# AutomationHub

## Project Status

Current stage: Electron integrated with Vite. The first feature (Restart Discord) is implemented and ready for UI verification.

## Goal

AutomationHub is a Windows desktop application that allows users to automate repetitive desktop actions through a clean graphical interface.

The application should eventually support:

- Launch applications
- Close applications
- Restart applications
- Execute command sequences
- Global hotkeys
- Macros
- User profiles
- Startup automation
- Plugin system
- Custom workflows

The project should prioritize maintainability and scalability over fast feature implementation.

## First Functional Goal

Implement a working desktop application capable of restarting Discord.

Expected flow:

User presses button

↓

Electron receives request

↓

Discord process terminates

↓

Discord launches again

↓

UI displays success message

This feature validates the complete application architecture.

---

## Long-Term Vision

AutomationHub should evolve into a desktop automation platform rather than a collection of scripts.

Every feature should be modular.

Every system should be replaceable.

Architecture must remain clean from the beginning.
