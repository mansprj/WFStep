# Анализ конкурентов WF Step

Дата анализа: 19 августа 2026

---

## Напоминание: Что такое WF Step

**WF Step** — это десктопное приложение для Windows, которое позволяет автоматизировать повторяющиеся действия через чистый графический интерфейс.

### Ключевые особенности:
- **Управление процессами**: поиск, убийство, перезапуск, запуск, статус
- **Библиотека приложений**: сохранение приложений по пути/имени процесса, запуск/перезапуск/остановка
- **Действия автоматизации**: запуск/остановка/перезапуск приложений, задержка, shell-команды, открытие URL/папки
- **Воркфлоу**: объединение действий в последовательности, пошаговое выполнение с прогрессом и отменой
- **Горячие клавиши**: назначение шорткатов на воркфлоу, запуск отовсюду
- **Системный трей**: приложение работает в фоне, закрытие = свернуть в трей

### Технологии:
- Electron + React + TypeScript + Vite
- Только Windows (пока)
- Нет AI/машинного обучения
- Нет визуального редактора узлов (node-based)
- Нет записи действий (macro recording)
- Нет браузерной автоматизации

### Долгосрочная цель:
Превратиться в платформу десктопной автоматизации с плагинами, профилями и расширяемой архитектурой.

## Категории конкурентов

### 1. ПРЯМЫЕ КОНКУРЕНТЫ (ближе всего по духу и функционалу)

### 1.1 Keybind
**Сайт**: https://keybind.net/
**Статус**: Активно развивается, бесплатная версия + Pro ($4.99/мес)
**Платформа**: Windows 10/11

**Что это**: Всё-в-одном приложение для автоматизации Windows. Сделано для людей, которые считают, что AutoHotkey должен быть лучше.

**Ключевые фичи**:
- Горячие клавиши (как у WF Step)
- Скрипты на KSL (собственный язык)
- Голосовое управление (полностью on-device)
- Планировщик (cron, startup, folder-watch)
- Flows (визуальные последовательности)
- Модули + маркетплейс
- Screen OCR, clipboard history
- BYO-key AI
- .exe компилятор для портативных автоматизаций

**Сходства с WF Step**:
- Горячие клавиши на воркфлоу
- Системный трей
- Локальное выполнение
- Бесплатная версия

**Отличия от WF Step**:
- Намного больше возможностей (голос, OCR, планировщик)
- Собственный язык скриптов (KSL)
- Маркетплейс модулей
- AI интеграция
- Pro версия с cloud sync

**Оценка угрозы**: 🔴 ВЫСОКАЯ — прямой конкурент, но с гораздо бо́льшим функционалом.

---

### 1.2 Clockwork
**GitHub**: https://github.com/rockbenben/Clockwork
**Статус**: Бесплатный, open-source
**Платформа**: Windows 10/11

**Что это**: Трей-утилита для автоматизации запуска приложений, напоминаний и групп действий.

**Ключевые фичи**:
- Список запуска (автозапуск приложений при входе)
- Запланированные задачи (напоминания, запуск групп)
- Группы действий (Action Groups) — routines как "Фокус", "Встреча", "Завершение дня"
- Горячие клавиши для запуска групп
- Управление автозапуском системы
- 18 языков интерфейса
- Один .exe файл, не требует установки

**Сходства с WF Step**:
- Горячие клавиши
- Системный трей
- Запуск групп действий (похоже на воркфлоу)
- Windows only

**Отличия от WF Step**:
- Проще — нет редактора воркфлоу, нет библиотеки приложений
- Больше фокус на автозапуск и расписание
- Нет управления процессами (kill/restart)
- Нет shell-команд
- Нет плагин-системы

**Оценка угрозы**: 🟡 СРЕДНЯЯ — похожий дух (простая автоматизация из трея), но меньше возможностей.

---

### 1.3 FlowSwitch
**GitHub**: https://github.com/jmpanackal/FlowSwitch
**Статус**: В разработке, open-source
**Платформа**: Windows (primary)

**Что это**: Десктопное приложение для создания профилей активности (Gaming, Work, Editing), которые запускают приложения и настраивают окна одним кликом.

**Ключевые фичи**:
- Профили активности (как "Рабочий", "Игровой")
- Запуск приложений, файлов, браузерных вкладок
- Восстановление раскладки окон по мониторам
- Настройка громкости
- Расписание и автозапуск
- Сканирование установленных приложений

**Сходства с WF Step**:
- Electron + React + TypeScript + Vite (почти идентичный стек!)
- Библиотека приложений (похоже на Applications Library)
- Профили (похоже на Phase 6: Profiles в roadmap WF Step)
- Системный трей

**Отличия от WF Step**:
- Нет воркфлоу-движка (только профили)
- Нет горячих клавишей для воркфлоу
- Нет shell-команд
- Нет управления процессами
- Больше фокус на раскладку окон и мониторы

**Оценка угрозы**: 🟡 СРЕДНЯЯ — очень похожий стек технологий, но проще по функционалу.

- Больше фокус на безопасность (шифрование)

- Шорткаты на главном экране

**Сходства с WF Step**:
- Воркфлоу из нескольких действий
- Горячие клавиши
- Системный трей
- Планировщик

**Отличия от WF Step**:
- Фокус на скрипты (C#/PowerShell), а не на визуальные действия
- Нет drag-and-drop редактора
- Нет библиотеки приложений
- Более "разработчик-oriented"

**Оценка угрозы**: 🟢 НИЗКАЯ — другой подход (скрипты vs GUI).

## 2. AI--powered десктопная автоматизация (продвинутые конкуренты)

### 2.1 Atlas
**GitHub**: https://github.com/dortanes/atlas
**Статус**: Бесплатный, open-source
**Платформа**: Windows (macOS/Linux planned)

**Что это**: AI-powered десктопный агент, который понимает экран и автоматизирует задачи через Gemini API.

**Ключевые фичи**:
- Захват экрана и понимание контекста
- Планирование многошаговых задач
- Управление мышкой, клавиатурой, терминалом
- Видимый курсор (видно, что делает AI)
- Computer Use API (Gemini 3.x)
- Оверлей с хоткеем (Ctrl+Space)
- Системный трей

**Сходства с WF Step**:
- Electron
- Горячие клавиши
- Системный трей
- Автоматизация десктопа

**Отличия от WF Step**:
- Полностью AI-driven (нужен Gemini API ключ)
- Нет ручного создания воркфлоу
- Видит экран через скриншоты
- Может работать с любым приложением
- Гораздо сложнее архитектура

**Оценка угрозы**: 🟡 СРЕДНЯЯ — другой подход (AI vs ручная настройка), но решает похожие проблемы.

### 3.1 Loopi
**GitHub**: https://github.com/dyan-dev/loopi
**Статус**: Open-source, активно развивается
**Платформа**: Windows, Linux

**Что это**: Open-source платформа десктопной автоматизации с визуальным конструктором, браузерным контролем, AI агентами и 80+ интеграциями.

**Ключевые фичи**:
- Drag-and-drop редактор узлов (ReactFlow)
- Браузерная автоматизация (Chromium)
- Десктопный контроль (мышь, клавиатура, hotkeys)
- Shell-команды
- AI агенты (OpenAI, Anthropic, Ollama)
- 80+ API интеграций
- Планировщик (cron, interval)
- CLI
- Локальное выполнение

**Сходства с WF Step**:
- Electron + React + TypeScript
- Визуальный конструктор (но нод-based vs простой список)
- Горячие клавиши
- Shell-команды
- Локальное выполнение

**Отличия от WF Step**:
- Намного больше возможностей (браузер, AI, 80+ интеграций)
- Node-based редактор (сложнее, но мощнее)
- AI агенты с self-patching
- Кроссплатформенный

**Оценка угрозы**: 🔴 ВЫСОКАЯ — самый близкий по духу open-source конкурент с гораздо бо́льшим функционалом.

## Анализ позиционирования WF Step

### Уникальные сильные стороны WF Step:
1. **Простота** — нет node-based редактора, нет AI, нет скриптов. Просто действия → воркфлоу → горячие клавиши
2. **Process Management** —很少有 конкурентов сочетают process management + workflows + hotkeys в одном приложении
3. **Applications Library** — сохранение приложений с путями и перезапуск — уникальная фича
4. **Clean Architecture** — Electron + IPC + React, подготовленная для плагинов
5. **Бесплатность** — полностью бесплатный, open-source potential

### Где WF Step отстаёт:
1. **Визуальный редактор** — Loopi, ForgeFlow, Autopath, Clickweave имеют node-based редакторы
2. **AI интеграция** — большинство новых конкурентов добавляют AI
3. **Браузерная автоматизация** — Loopi, Autopath, ShellForge поддерживают
4. **Планировщик** — нет cron/schedule (только hotkeys)
5. **Кроссплатформенность** — только Windows
6. **Macro Recording** — нет записи действий (TinyTask, Clickweave, KeyMaster Pro имеют)
7. **Shell-команды** — есть, но нет продвинутого вывода/логирования

### Рекомендации по развитию:
1. **Добавить визуальный редактор** — node-based для воркфлоу (как Loopi/ForgeFlow)
2. **Добавить планировщик** — cron/schedule триггеры
3. **Добавить macro recording** — запись действий и воспроизведение
4. **Добавить shell output view** — логирование результатов команд
5. **Рассмотреть AI** — хотя бы базовую интеграцию (опционально)
6. **Кроссплатформенность** — macOS/Linux в будущем

---

## Заключение

WF Step занимает нишу **простого, минималистичного инструмента** для автоматизации десктопа без лишней сложности. Это его сила и слабость одновременно.

**Прямые конкуренты** (Keybind, Loopi, ForgeFlow) предлагают гораздо больше функций, но WF Step может выиграть за счёт:
- Простоты использования
- Чистой архитектуры (готов к плагинам)
- Фокуса на core features (process management + workflows + hotkeys)

**Стратегия**: Не пытаться конкурировать с Feature-rich конкурентами, а сделать **самый простой и надёжный** инструмент для своей ниши, а затем расширяться через плагины.
